# BuJo PWA — 로그 생성 규칙

## 탭 구조

```
Future Log  ←  Monthly Log  ←  Daily Log
(가장 추상적)                  (가장 구체적)
```

- `<` : 오른쪽 → 왼쪽 (더 미래/추상으로 예약)
- `>` : 왼쪽 → 오른쪽 (더 구체적으로 이동, Future → Monthly만 해당)

---

## Future Log

### 생성 규칙
- **날짜**: 연(year) + 월(month)만 지정. 일(day) 없음.
- **용도**: 특정 날짜가 정해지지 않은 미래의 계획, 아이디어, 목표.
- **Composer**: 월 셀렉터에서 해당 월 선택 후 입력.

### 항목 이동
| 동작 | 방향 | 설명 |
|------|------|------|
| `>` | Future → Monthly | 구체적인 날짜(월.일)가 정해졌을 때 Monthly로 이동 |
| `<` | 해당 없음 | Future보다 왼쪽 개념 없음 |

---

## Monthly Log

### 생성 규칙
- **날짜**: **월.일 필수** (캘린더 피커에서 선택, 빈 값 불허).
- **용도**: 해당 월에 처리할 예정인 구체적인 task/event/note.
- **날짜 미정 항목**: Monthly Log가 아닌 **Future Log**에 기록할 것.

> **가이드라인**: "언제 할지 아직 모르겠다" → Future Log  
> "이번 달 X일에 한다" → Monthly Log

### 항목 이동
| 동작 | 방향 | 설명 |
|------|------|------|
| `<` | Monthly → Future | 날짜가 더 멀어졌을 때 Future로 재예약 |
| `>` | 해당 없음 | 날짜가 이미 지정되어 있으므로 수동 이동 불필요 |

### 자동 Daily 이관 (시스템)
- **매일 첫 접속 시** 오늘 날짜(`scheduledDate`)가 오늘인 Monthly 항목을 자동으로 Daily Log에 생성.
- Monthly 항목은 그대로 유지(참조용), Daily에 `origin: from-monthly`로 복사됨.
- 이미 이관된 항목(중복)은 건너뜀.

---

## Daily Log

### 생성 규칙
- **날짜**: 해당 일의 날짜로 자동 지정 (현재 보는 날의 log).
- **용도**: 오늘 실제로 처리하는 task/event/note.
- **Composer**: 날짜 선택 없이 바로 입력.

### 항목 이동
| 동작 | 방향 | 설명 |
|------|------|------|
| `<` | Daily → Monthly | 오늘 못 하고 이번 달 다른 날로 미룰 때 (수동) |
| `>` | 해당 없음 | Daily보다 오른쪽 개념 없음 |

### 자동 이월 없음 + 밀린 항목(Migration) 노출
- 어제의 미완료 task를 오늘로 **자동 이월하지 않는다.** (마감 압박 방지)
- 대신 **오늘 Daily Log 상단에 "밀린 항목" 섹션**을 노출한다.
  - 대상: 오늘 이전 날짜의 모든 미완료(`open`) task.
  - 각 항목마다 3가지 선택: **오늘로 가져오기 / 완료(✓) / 취소(✕)**.
  - "오늘로 가져오기" 시 오늘 Daily에 복사(`origin: migrated`)하고 원본은 `migrated` 처리.
- 이는 BuJo의 핵심 의식인 **Migration(이관)** 을 화면에 옮긴 것으로,
  자동 이월(압박)도 방치(망각)도 아닌 "보여주되, 옮길지는 내가 결정" 방식이다.

## 전체 흐름 요약

```
아이디어/장기계획
        ↓ 입력
   [Future Log]  (연월만, 날짜 미정)
        ↓  >  날짜 확정 시
   [Monthly Log] (월.일 필수)
        ↓  자동 (당일 첫 접속)
   [Daily Log]   (오늘 처리)

  ※ 미완료 task는 자동 이월되지 않음 — 필요 시 < 로 수동 재배치
```

---

## TaskStatus 값 정의

| 값 | 의미 |
|----|------|
| `open` | 미완료 (기본값) |
| `completed` | 완료 |
| `cancelled` | 취소 |
| `migrated` | 다음 날/로그로 이월됨 |
| `scheduled` | 다른 로그로 예약/이동됨 |
